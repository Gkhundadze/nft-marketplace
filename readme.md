# NFT Marketplace

ეს არის სასწავლო პროექტი, რომელსაც ვქმნით **Skillwill-ის სტუდენტებთან ერთად მარკირების ლექციის ფარგლებში**.

პროექტის მიზანია რეალური Figma დიზაინის მიხედვით ვებგვერდის ეტაპობრივად აწყობა და ამ პროცესში თანამედროვე HTML/CSS მიდგომების პრაქტიკაში გამოყენება.

## პროექტის შესახებ

პროექტის დიზაინი შექმნილია Figma-ში და მისი მიხედვით ეტაპობრივად ვაწყობთ **NFT Marketplace-ის** ინტერფეისს.

პროექტზე მუშაობისას ყურადღება ექცევა არა მხოლოდ დიზაინის ვიზუალურად გამეორებას, არამედ:

- Figma დიზაინის ანალიზს
- გვერდის სტრუქტურის სწორად დაგეგმვას
- HTML-ის სემანტიკურ სტრუქტურას
- პროექტის ფაილების სწორ ორგანიზებას
- თანამედროვე CSS მიდგომებს
- reusable კლასების შექმნას
- responsive დიზაინს

## სასწავლო მიზნები

პროექტზე მუშაობისას განვიხილავთ და პრაქტიკაში ვიყენებთ:

### Design Analysis

Figma დიზაინის ანალიზი და მისი HTML/CSS სტრუქტურად გარდაქმნა.

### Project Structure

პროექტის ფაილებისა და სტილების ლოგიკური ორგანიზება, რათა კოდი იყოს მარტივად წაკითხვადი და გასაფართოებელი.

### CSS Variables

განმეორებადი მნიშვნელობების, მაგალითად ფერების, ზომებისა და სხვა დიზაინის მნიშვნელობების CSS variables-ად გამოყოფა.

### Utility Classes

მცირე, reusable utility კლასების გამოყენება განმეორებადი სტილების სამართავად.

### CSS Nesting

თანამედროვე CSS nesting-ის გამოყენება სტილების უფრო ორგანიზებულად დასაწერად.

### Container

საერთო `.container` კლასის შექმნა და გამოყენება გვერდის ძირითადი content-ის ზომისა და განლაგების სამართავად.

## პროექტის განვითარება

პროექტი ვითარდება ეტაპობრივად, ლექციების მიმდინარეობის პარალელურად.

პირველ ეტაპზე შევქმენით პროექტის საწყისი სტრუქტურა და ავაწყეთ Header-ის ნაწილი. ამავე ეტაპზე განვიხილეთ დიზაინის ანალიზი და თანამედროვე CSS-ის ძირითადი მიდგომები, რომლებსაც პროექტის განვითარებასთან ერთად გამოვიყენებთ.
